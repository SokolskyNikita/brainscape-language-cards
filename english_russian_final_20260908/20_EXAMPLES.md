# 20 examples from the English → Russian final pass

These are selected corrections and sense clarifications. The complete log contains all 613 changed cards.

| English | Before | After |
|---|---|---|
| b | б | би (название латинской буквы b) |
| pier | мол | пирс, пристань |
| vital | жизненный | жизненно важный |
| expertise | опыт | специальные знания, компетентность |
| nationality | национальность | гражданство; национальность (этническая принадлежность) |
| gymnasium | гимназия | спортивный зал; гимназия (тип школы в некоторых странах) |
| lard | сало | смалец, топлёное свиное сало |
| ensign | прапорщик | энсин (младший офицер ВМС США); прапорщик (историческое звание); военно-морской флаг |
| groat | грош | гроут (старинная британская монета) |
| to be jealous | ревновать | ревновать (в отношениях); завидовать |
| fir | ель | пихта |
| Hindu | индус | индуист (последователь индуизма); индус |
| graduate school | аспирантура | магистратура; аспирантура (последипломное обучение) |
| handcuff | наручник | наручники (обычно handcuffs); один браслет наручников |
| get into the swing of things | войти во вкус | войти в ритм, освоиться |
| utilization | утилизация | использование; утилизация (отходов) |
| unlearn | разучиться | отучиться от; отказаться от усвоенного |
| religiously | набожно | неукоснительно, неизменно; набожно (в религиозном смысле) |
| principality, duchy | княжество | княжество (principality); герцогство (duchy) |
| compass, compasses | компас | компас (навигационный прибор); циркуль (a pair of compasses) |

Examples were also aligned with the corrected meanings. For example:

“She follows this rule religiously.” → «Она неукоснительно следует этому правилу.»

“We need to unlearn these habits.” → «Нам нужно отучиться от этих привычек.»

“She will get into the swing of things soon.” → «Она скоро войдёт в ритм.»
